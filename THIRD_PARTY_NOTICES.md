# Third-party build tooling

`gradlew`, `gradlew.bat`, and `gradle/wrapper/gradle-wrapper.jar` are the official
Gradle 8.14.3 wrapper files. They are licensed under the Apache License 2.0;
see [gradle/wrapper/LICENSE](gradle/wrapper/LICENSE).

Build dependencies are downloaded from their official repositories. Their code
is not copied into Foxcraft's content sources. Fabric API is a separate runtime
dependency on Fabric; NeoForge supplies its runtime APIs itself.
