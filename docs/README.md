# Foxcraft documentation

Foxcraft is a Minecraft Java **1.21.1** mod for Fabric and NeoForge.
Start with the [root README](../README.md) to build and install it, then use
[Editing content](editing-content.md) for everyday changes.

| Upgrade Minecraft or loader versions | [Updating Minecraft](updating-minecraft.md): version pins, isolated API changes, resource-format boundaries, and saved identities. |
